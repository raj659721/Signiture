# Signature Builder - Professional Signature Creator

A professional and highly customizable email signature generator built with modern web technologies. This tool allows users to easily design, customize, and export professional email signatures for themselves or their teams.

## 🚀 Features

- **Professional Templates**: Choose from a variety of sleek, modern designs to suit your brand.
- **Real-Time Preview**: See your signature update instantly as you edit the details.
- **Customizable Details**: Add your name, job title, company, contact info, social links, and profile image.
- **Responsive UI**: A beautiful, user-friendly interface powered by Tailwind CSS and Radix UI primitives.
- **One-Click Export**: Easily copy the generated signature HTML or simply copy it directly to your clipboard to paste into Gmail, Outlook, or Apple Mail.
- **Secure Data Storage**: Powered by Supabase for reliable data management and potential team sharing features.

## 🛠️ Technology Stack

- **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend/Database**: [Supabase](https://supabase.com/)
- **Language**: TypeScript

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/raj659721/Signiture.git
   cd Signiture
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173` to view the application.
